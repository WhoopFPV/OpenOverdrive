# OpenOverdrive

<img src= "https://raw.githubusercontent.com/WhoopFPV/OpenOverdrive/26c7d8f1c13672ab88b30b42efaadedf9b01a2a3/assets/logo.png" alt="Logo" width="200" height="200">  
An Anki Overdrive (3.4) backend for syncing data and more, also works completely offline!

## How to run
First Step: Install NodeJS from https://nodejs.org/en/download \
Second Step: Download this repository as the zip and extract it \
Third Step: Run setup.bat (or `npm i` in a console window) \
Fourth Step (Optional): Get the rams and add them to the server (Im not allowed to share them) \
Fifth Step and last: Run start.bat (or `node index.js`) and patch your app

## How to patch (Android)
Close Anki Overdrive \
Make sure its not patched yet \
Connect phone to your PC and enable data transfer, and run patch_android.bat \
Then enter your IP WITHOUT THE /1/ OR HTTP
If the patcher closes unplug your phone and its patched! \
